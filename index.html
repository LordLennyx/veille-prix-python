Chaque matin, les prix de vos concurrents, sans copier-coller.

Un robot Python parcourt les catalogues de trois boutiques en ligne, rapproche les mêmes produits, détecte baisses de prix et ruptures, puis livre un classeur Excel et ce tableau de bord. Ici, il tourne sur des boutiques de démonstration fournies avec le code.

1. Collecter
Respect du robots.txt, délai entre requêtes, nouvelles tentatives, pagination suivie automatiquement.
2. Extraire
Une boutique = quelques sélecteurs CSS dans un fichier JSON. Aucun code à modifier pour en ajouter une.
3. Comparer
Rapprochement des produits entre boutiques, historique SQLite, alertes au-delà de 3 % d'écart.
4. Livrer
CSV compatible Excel, classeur mis en forme, JSON pour un tableau de bord ou une alerte e-mail.
